# Fundamental Event Specialist

The specialist owns company filings and fundamentals, not macro headlines or another price-only
momentum ranking. Its operational context is distinct from the three broad price-model evidence
packs and does not automatically cast another market-wide vote.

## Interpretation

The desk runner invokes the event repository's `daily` CLI in its isolated environment. That
command stores an immutable observation, including blocked status. Portfolio Lab verifies the
observation's status hash and copies the source access, readiness, actually tested hypothesis
count, frozen targets and available research evidence into the desk archive. It does not turn a
failed acquisition into a cash, neutral or bearish signal.

The Event research workspace shows acquisition responses, historical-data requirements, research
stage and remaining admission gates. Qualified current captures can show native development,
validation and lockbox metrics and source-bound events. Current targets and completed research
outcomes are withheld for historical session selections. The written readout includes the same
operating status rather than silently omitting an inactive bot.

## Comparative Portfolio Research

An event runtime must be explicitly configured using a qualified real historical dataset and
an audited frozen native report. `export-all` then invokes its native common-contract exporter.
The research runner accepts the three core specialists plus that qualified event bundle; it
still rejects unknown specialists and empty substitute experts.

Event bundles require hash-bound `qualification.json` and `terminal_events.json`. Fixture status,
dataset/research identities, code identity and denial of automatic allocation must reconcile.
Missing or failed qualified exports fail the research run rather than silently excluding a
configured specialist. The existing desk can still show its blocked operational context.

The common engine uses next-close execution; the native event engine uses next-open execution.
These are separate, labeled tests. Both fund transaction costs from capital and model explicit
terminal cash, including zero recovery. A common price source must use the same adjusted-share
units as the terminal payout; otherwise the comparison is rejected.
