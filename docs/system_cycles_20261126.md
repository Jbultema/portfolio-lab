# Five-Cycle Trading System Implementation And QC

Research-only, human-executed ordinary securities and cash. No automatic promotion,
broker action, paid subscription, historical-evidence rewrite, or external narration.

## Acceptance

Each numbered cycle requires implementation, focused/adversarial tests, the complete
five-repository software suite, a defect survey and corrective pass, and a release
checkpoint. Local tests, local source cleanliness, personal-SSH push, PR state and
remote CI are distinct gates. Unknown remote status is never reported as clean.
Existing unrelated work, historical captures and raw data must be preserved.
