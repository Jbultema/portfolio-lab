# Trading System Assessment After Five Improvement Cycles

## Operational Conclusion

Retain the operating primary. The system is a more auditable research and market
interpretation platform, not a newly proven source of higher future returns.
The new staged-risk rules did not establish an improvement and are not promoted.
Original worktrees and running applications were preserved. This release is in
personal review branches, not merged main or an accepted live-trading release.

## What Changed

1. Canonical native identities now identify the actual configured i111 primary,
   monthly Swing primary and bound Rotation selection. Event has no admitted
   broad primary. Release receipts bind tested executable source and dependency
   checks; cross-checkout editable-install leakage is corrected.
2. Rotation holds drifting units and funds fees from portfolio NAV. Independent
   share-ledger tests and frozen rebaselines replace free-rebalancing assumptions.
   True equal-sector buy-and-hold is about 8.09% CAGR, not the legacy 9.19% path.
3. Twenty-four native cash-risk variants were tested on the actual primary and
   risk-repair challenger, with unchanged/static controls, costs, delays, uncertainty
   and crisis omissions. No new rule has a positive slate-adjusted comparison.
4. Planned exchange reviews replace end-of-file weekly/monthly reviews. Specialist
   ownership and economic-overlap evidence are explicit. Data, prospective and
   human-review gates remain closed where evidence is absent. Inventory diagnostics
   redact URL credentials and ignored executable sources fail release checks.
5. System Scorecard exposes funded performance/drawdown, costs/delays, specialist
   overlap, source-bound forecast accountability and separate release gates.
   Forecasts cannot be backdated from historical briefs or multiplied into
   independent evidence by overlapping labels. No actual prospective forecasts
   or calibrated prediction edge are claimed yet.

## Performance Interpretation

Latest funded common-clock comparison: 2008-04-09 to 2026-11-25, 25bp per traded
side, next-close fills. Current primary: **17.59% CAGR / -26.57% max DD**.
Gentle staged risk: **16.39% / -26.26%**. Confirmed staged risk:
**15.64% / -27.67%**. Explicit repair: **15.81% / -27.82%**.
Static 85% risk control: **17.59% / -24.40%**. The risk-repair parent's static
85% control is **17.67% / -23.65%**, but growth trails its parent in 2019+ and
in the separate native execution comparison. This is not a new timing edge.

There are 30 candidates/controls, 180 native paths and 192 funded common-clock
paths. Corrective reruns of the same slate are not new hypothesis trials.
Removing the incumbent drawdown guard barely changes most staged paths; adding
confirmation itself is too restrictive here. Every new rule still loses return
after separately omitting 2020, 2022, or the sampled GFC interval.

Older 22%-CAGR headlines used other samples, execution and cost assumptions.
They are not a forward return expectation. Modern technology selection,
survivorship and already-inspected history still limit generalization. Native
Trade Bot's legacy accounting/control clock is not declared identical to the
funded common ledger; native/common parity remains an explicit research limit.

## Whole-System Read

- Trade Bot remains the strongest tested growth engine conditional on the
  selected modern universe. Technology concentration remains a real structural risk.
- Swing and Rotation are differentiated price-driven decisions, not independent
  information sources. Diversification can smooth drawdown without improving
  growth relative to Trade plus cash. Correlation alone does not qualify a sleeve.
- Event/news integration works as source-bound context and conditional research.
  Broad historical company-event alpha remains data-gated, not ready for allocation.
- Market Desk has a fresh isolated 40-session reconstruction, October 1 through
  November 25, with all 40 sessions fully fresh across the three core providers.
  States: 27 fragile transition, five defensive stress, five mixed, three broad
  risk-on. This is a descriptive replay, not calibrated crash probabilities.
- The new prospective journal and Brier/base-rate scoring are implemented, but
  future observations cannot be supplied retrospectively. An agent estimate is
  not a calibrated probability merely because it has a number and cited facts.

## Remaining Gates

historical identities, original filing/news vintages and verified terminal prices.
No paid data or relaxed public-data standard was authorized. The original weekly
pre-bubble snapshot project remains distinct; this cash-risk study does not
silently substitute for completing it.

Independent prospective evidence and additional regimes remain necessary.
The native Trade accounting migration must preserve old archives and explicitly
reconcile decision clocks before legacy headline returns can be treated as ledger
conformance evidence. These software cycles do not resolve that historical claim.

Local QA, personal SSH publication, PR review and remote CI are different gates.

account, which was not used for personal PR operations. PR creation/acceptance is
therefore incomplete; no main branch was merged or force-pushed. Protected raw
macro data, decision journals and original source WIP remain in their original
checkouts rather than being deleted to manufacture cleanliness.
